# Inventario de suelas

Programa web para llevar el inventario de suelas: fotos, pedidos con llegadas parciales, faltantes/sobrantes, total a pagar y fecha de cada llegada.

## Cómo correrlo
```bash
npm install
npm start
```
Abre http://localhost:3000. Desde un celular en el mismo WiFi: `http://IP-DEL-PC:3000`.

Contraseña opcional (recomendada si lo publican en internet): define `APP_PASSWORD` antes de iniciar.

Los datos y las fotos se guardan en la carpeta `data/` (no se sube a GitHub).
